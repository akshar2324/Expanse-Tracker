# AkSpend 1.6.0

## Changes

- Add an expense from Android Quick Settings.
- Enable optional monthly category budget notifications at 80% and 100%, with one alert per threshold per month.
- Build and share an offline monthly PDF with totals, category spending, top expenses and budget comparisons.
- Swipe Activity entries right to edit or left to delete. Undo restores the original transaction, including both legs of a transfer.
- Use the Soft appearance with preset palettes and custom colours.
- Read full account names, amounts, chart legends and tabs at larger font sizes.
- Get in-app status messages and inline form errors.
- Use a one-line Activity search hint and more widely spaced date filters.
