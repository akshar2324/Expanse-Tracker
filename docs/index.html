04 / FEATURES EVERYTHING ON-DEVICE

Everything a ledger should do.
Nothing it shouldn't.

  • ACCOUNTS

    Many accounts, one honest total

    Cash, bank, wallet, savings and credit cards. Transfers move money between them without counting as income or spending, and reconciliation keeps balances true.

  • BUDGETS

    Limits and goals

    Weekly or monthly budgets per category, plus savings goals that track themselves.

  • INSIGHTS

    A weekly digest

    Top categories, unusual spends and a month-end forecast, computed on the phone.

  • IMPORT

    Bring your statements

    Import bank or wallet CSVs in a staged review. Duplicates are caught by row fingerprint.

  • LOCK

    Biometric lock

    Fingerprint or face unlock, backed by the Android keystore.

  • BACKUP

    Backups you hold

    Export a JSON backup or the raw database and restore it whenever you like. Android cloud backup is switched off.

  • EVERYDAY

    The small things that make it stick

    Recurring transactions, money you've lent or borrowed, a quick-add home-screen widget, and light and dark themes that follow your phone.

07 / INSTALL ABOUT A MINUTE

  1. 01

    Download the APK

    On your Android phone, tap Download APK. It opens the latest release on GitHub. Tap the file ending in .apk.

  2. 02

    Allow this one install

    Android asks before installing apps from outside the Play Store. Tap Settings, turn on Allow from this source for your browser, then go back.

  3. 03

    Install and open

    Tap Install, then Open. There's no sign-up: you're logging your first expense straight away. You can turn the browser permission off again afterwards.

IS IT SAFE?

You don't have to trust us. You can check.

  • No internet permission. An app's manifest lists what it's allowed to do, and AkSpend's has no internet access, so it can't send your data anywhere. Check it in the source or with any APK inspector app.
  • Built from public code. Every release is built from the open-source repository, so anyone can read exactly what it does.
  • Only download from this page or the GitHub releases page. Copies of the APK on other sites aren't ours.
