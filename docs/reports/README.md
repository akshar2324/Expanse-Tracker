# Monthly PDF report demo

`monthly-report-demo.pdf` contains fabricated November 2026 transactions and monthly budgets only. It is generated by `MonthlyReportPdfTest` with the same `android.graphics.pdf.PdfDocument` writer used by the app, on an Android emulator. It is not evidence of physical-phone testing.

To regenerate, build and install the debug app and Android test APKs on a disposable emulator, then run `MonthlyReportPdfTest` through AndroidJUnitRunner. Copy `cache/monthly-report-demo.pdf` from the app sandbox here. No phone data is used.

In the app: More → Monthly report → choose a month → Build report → Share. The preview stays in memory. Only Share creates a temporary PDF in private cache and opens the Android system share sheet. The report omits transaction notes, payees, payment methods and account details. It includes monthly budgets for the selected month; weekly budgets have separate periods and are not included.
