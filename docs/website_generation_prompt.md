# AkSpend Website Generation Prompt

Use this prompt with an AI website builder or IDE to create a professional, high-converting landing page for the AkSpend app.

---

**Prompt:**

Act as a world-class Senior Web Designer and Frontend Developer. Create a high-end, modern landing page for a fintech app called **AkSpend**.

### Brand Identity:
- **Core Value:** "Private. Offline. Secure."
- **Niche:** A 100% offline personal finance ledger that never sends data to the cloud.
- **Theme:** "Obsidian & Emerald" (Dark, premium, trust-focused).
- **Primary Color:** Emerald Green (#34D399).
- **Secondary Color:** Navy Deep (#0F172A).
- **Accent:** Navy Light (#1E293B).

### UI/UX Style:
- **Design Language:** High-end Fintech (similar to Linear, Stripe, or Vercel).
- **Features:** Glassmorphism, subtle bento-grid layouts, smooth scroll animations (Framer Motion style), and glowing accent blurs.
- **Typography:** Inter or Sans-serif, bold headlines, clean readable body text.

### Page Structure & Content:
1. **Navbar:** Minimalist with Logo (AkSpend), Features, Privacy, and a "Download APK" CTA button.
2. **Hero Section:** 
   - Headline: "Smart finance tracking that never leaves your phone."
   - Subheadline: "A 100% offline, private financial ledger. No cloud, no trackers, absolute security."
   - CTA: Large "Install Now" button with a glowing emerald effect.
   - Graphic: A sleek mobile mockup showing a financial dashboard.
3. **The Bento Grid (Features):** 
   - Multi-Currency Ledger.
   - Categorized Monthly Budgets with progress bars.
   - Savings Goals & Milestones.
   - Offline Privacy Model.
4. **Privacy Manifesto:** A high-contrast section explaining the "Zero-Server" model. Use icons for "No Cloud Accounts," "Isolated Database," and "No Background Trackers."
5. **Roadmap:** A vertical timeline showing upcoming features like "AI Budgeting Assistant" and "Encrypted Backups."
6. **Footer:** Links to Privacy Policy, Terms, and Support Email (axar2324@gmail.com).

### Technical Requirements:
- Use **Tailwind CSS** for all styling.
- Ensure the site is fully responsive (Mobile, Tablet, Desktop).
- Include Meta tags for SEO and OpenGraph (for Play Store verification).
- Use Lucide-react or Phosphor icons.
- Ensure all emerald accents use a "glow" or "glow-ring" effect to match the app's logo.
